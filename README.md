# 潮解密：個案文件去識別化工具（macOS）

把 docx、xlsx、PDF、圖片、txt 裡的姓名、身分證、電話、生日、地址、電子郵件、統一編號換成〔個案01〕這類代號，另存一張對照表；需要時再用對照表換回原文。**全程在你自己的電腦跑，不連網、不接任何 AI 服務。** 給社工、治療師、輔具與長照單位在把文件交給外部 AI 或外部單位之前用。

作者只有 Mac，**只正式支援 macOS（Apple Silicon）**，Windows 歡迎自行移植（見最後一節）。

做法一半自己開發，一半參考他人公開的去識別化工具（整批共用代號、xlsx 直接改 XML、部分保留、電子郵件與統一編號、Claude 協助撰寫程式）。

## 它會做什麼、不會做什麼

- 姓名**只換你名單上的**，不猜。沒給名單也能跑，但姓名不會換。
- 身分證、電話、生日、地址、電子郵件、統一編號用規則自動認（規則見下）。
- 每個檔產一張對照表（JSON），**那張就是個資**，工具預設放在 `~/去識別對照表/`，請不要跟去識別版放一起、不要上傳。
- 產完會做殘留檢查：把去識別版的字抽回來，對照表上每個真值再找一遍，還找得到就標「⚠ 殘留」。但**它只能查它自己認到的值**，名單漏給、手寫字、寫法太怪的地址不在對照表裡，查不到。交出去前請自己看一遍。
- 掃描 PDF 與圖片用 macOS 內建的 Vision 做 OCR 後塗黑，**不可還原**。
- 文件屬性（作者、最後修改者、PDF 屬性、圖片 EXIF）一律清空。

## 安裝（兩種擇一）

**A. 直接用打包好的 .app**：到 Releases 下載 zip，解壓後雙擊。第一次會被 macOS 擋「無法驗證開發者」：到「系統設定 → 隱私權與安全性」往下捲，按「強制打開」。只能在 Apple Silicon（M1 以後）的 Mac 跑。

**B. 從原始碼跑**（Python 3.12）：

```bash
git clone <這個 repo>
cd chaojiemi
python3.12 -m venv ~/.venvs/deidentify
~/.venvs/deidentify/bin/pip install -r requirements.txt
~/.venvs/deidentify/bin/python app/main.py          # 開視窗；加 --debug 會開網頁檢查器
~/.venvs/deidentify/bin/python tests/run_all.py     # 跑測試，全部是假資料
```

要一個雙擊就開的 .app：`app/make_launcher.py` 做「啟動器」（.app 裡只有一支腳本去跑你的 venv，改程式不用重打包，預設 venv 路徑在檔案開頭的 `PY`）；`app/build.sh` 用 PyInstaller 打成自帶 Python 的 .app（約一分鐘、96 MB）。

## 視窗怎麼用

左欄拖檔案（可一批）。工具會掃「姓名：」「聯絡人姓名：」「承辦人員姓名：」這類欄位，把候選填進名單框（姓名歸個案、聯絡人與父母配偶歸家屬、承辦人與評估人員歸第三人），你核對後按「去識別」。右欄三個頁籤：去識別版預覽、換了什麼（預設不顯示真值，截圖前記得關）、OCR 全文（掃描件與圖片才有）。

在預覽上可以當場修：
- 點任何一個代號會浮出它的原文，確定要留原文就按「取消去識別，留原文」，整份檔那個值都留著，自動重跑。
- 用滑鼠圈一段字，選類別，「補遮成這一類」。
- 取消與補遮只記在這次開著的視窗裡；長期不換的字放名單的 `[不換]` 或「常用不換」。

「整批共用代號」：同一批檔裡同一個人在每個檔都是同一個代號，跑完會多存一張合併代號簿（本身也是個資）。下次「匯入上次代號簿」，舊的人沿用舊代號。

「部分保留」只給 xlsx 清冊：身分證留前 2 碼、電話留前 4 碼、地址留到鄉鎮市區；姓名與生日一律全遮。docx、PDF、掃描件沒有這顆開關。

## 指令列

```bash
python deidentify.py 某份檔案.docx --names 名單.txt
python restore.py 去識別版.docx 對照表.json
python restore.py 去識別版.docx 對照表.json --check-only   # 只檢查代號有沒有被改壞
```

`--out`、`--map` 改位置；`--retain` 部分保留（只對 xlsx 有效）；`--book 簿.json` 整批共用代號。

## 名單格式

```
[個案]
王小明
[家屬]
林美玲
[第三人]
張志豪
[不換]
某某輔具資源中心
某某市某某路1號
```

- 全名會換；「王小明先生」變「〔個案01〕先生」。
- 姓氏加稱謂（王先生、王小姐、王阿公…）：名單裡只有一個人姓王時換成〔個案01姓〕；兩個以上同姓就不換。
- 只剩名的「小明」不換，刻意的。
- `[不換]` 放機構名、機構地址。

## 自動認的六種

| 類別 | 認什麼 | 不認什麼 |
|---|---|---|
| 身分證 | 一個英文字母加 1、2、8、9 再八位數字，前後不接英數字。檢核碼不對的照樣遮，只標「⚠ 檢核碼不符」 | 財產編號裡夾的片段 |
| 電子郵件 | 標準寫法 | |
| 統一編號 | 八位數字且要過 112 年新制檢核碼 | 沒過檢核的八位數（案號、日期） |
| 電話 | 09 開頭十碼、0X 區碼市話 7 到 8 碼 | 案號、收據號、分機 |
| 生日 | 民國年 ≤ 99 或西元 1900 到 2010 的日期；或前 12 字內有「出生」「生日」的日期 | 受理日、聯絡日這類作業日期 |
| 地址 | 含「號」，且前面有路／街／鄉／鎮／區／村／里 | 只有鄉鎮名沒有門牌的 |

地址寫法最亂，被換的地址請在對照表裡看一眼。

## 設定檔與自訂

**路徑與常用不換**：`~/.config/chaojiemi/config.json`，沒有就用預設（去識別版 `~/Desktop/潮解密/去識別版/`、還原版在它底下 `還原/`、對照表 `~/去識別對照表/`）。

```json
{
  "out_dir": "~/Documents/去識別版",
  "map_dir": "~/對照表",
  "skip": ["某某輔具資源中心", "某某市某某路1號"]
}
```

**候選欄位詞**：`deid/candidates.py` 的 `LABELS`，一行一個「欄位標籤 → 類別」，長的標籤放前面。你的表單用別的欄名（例如「案主姓名」「主責社工」）就加在那裡。

**地址的鄉鎮錨點**：`deid/core.py` 的 `PINGTUNG_TOWNS` 是屏東縣 33 個鄉鎮市，用來判斷地址從哪個字開始。其他縣市的地址靠「某某縣／市」兩字錨點也認得到，但「潮州鎮光春路 292 號」這種沒寫縣市的，只有列在表裡的鄉鎮才認得準；換成你那個縣市的鄉鎮清單就好。

**字型**（只影響 PDF 還原版的字體）：文字層 PDF 還原時會依原字體家族挑系統字型，楷書優先找 `~/Library/Fonts/TW-Kai-98_1.ttf`（全字庫楷書，國家發展委員會免費提供，到 <https://data.gov.tw/dataset/5961> 下載後放進 `~/Library/Fonts/`），再找 Word 內建的楷體；都沒有才用內建中文字型，字體會跟原檔不同，內容不受影響。

## 各格式的做法與限制

- **txt／md／csv**：逐行換字，還原後逐位元相同。utf-8 讀不了就用 Big5。
- **docx**：以 run 層換字，保留字型與表格；正文、頁首頁尾、文字方塊、註腳、批註都掃。
- **xlsx**：直接改壓縮包裡的 XML，圖表、圖片、樣式、公式全部原樣；標題含「出生」「生日」的欄，日期型儲存格也換。存成數字的電話（開頭的 0 不見了）認不到。
- **文字層 PDF**：字元層級定位，遮白後把代號寫回原位；原值位置與字級記進對照表，還原放回原位。比對靠重抽文字，不是逐位元相同。
- **掃描 PDF 與圖片**：Vision OCR 定位後塗黑疊代號，整頁換成新圖，不可還原。手寫字認不到就會漏，產完請看 OCR 全文檔與黑框位置。影印機做的「可搜尋 PDF」也走這條，隱藏文字層一併清掉。
- pptx、音檔、影片不做。heic 不收。

## 螢幕上不印真名

工具的終端機輸出只印數量，不印任何真名、身分證、電話；真名只進對照表資料夾。因為終端機輸出常被複製進對話或日誌。

## 平台支援：只正式支援 macOS，Windows 歡迎自行移植

作者只有 Mac，**Windows 與 Linux 沒有實測過**。程式碼已經把 Mac 專用的部分隔開，照理在 Windows 用原始碼跑（`python app/main.py`）docx、xlsx、txt／csv、文字層 PDF 都能用，只有掃描 PDF 與圖片會以「此平台沒有 OCR」失敗。要補齊，改這三個地方：

| 檔案 | 現在 | 移植要做的 |
|---|---|---|
| `deid/ocr.py` | macOS Vision（pyobjc） | 換成 Windows 內建 OCR（`winocr`，要裝繁中語言包）或 Tesseract（`chi_tra`）。只要 `recognize()` 回傳的 `OcrLine.box` 維持「正規化座標、原點左下」，`substring_box()` 回傳同樣格式，其他檔不用動 |
| `deid/handlers.py` 的 `FONT_CANDIDATES` 與 `_font()` | 已列 Windows 的標楷體、細明體、微軟正黑體路徑，但沒驗 | 確認 `C:/Windows/Fonts/kaiu.ttf` 等檔名在你的 Windows 上存在 |
| `app/make_launcher.py` | 產 macOS 的 .app | 換成 .bat，或用 PyInstaller 打 .exe（`app/build.sh` 是 Mac 的打包指令） |

`app/main.py` 裡開資料夾用的是 `open`／`explorer`／`xdg-open` 三選一，Dock 圖示只在 macOS 做。pywebview 在 Windows 靠 Edge WebView2。
